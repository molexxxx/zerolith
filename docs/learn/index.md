# Learn zerolith

Each tutorial builds a small app from a fresh project, one step at a time. Every file a step shows runs in zerolith's own tests.

- [Packing list](packing-list/index.md): add, check off, filter, and undo items. Start here if zerolith is new to you.
- [Sign-up form](sign-up-form/index.md): check input as you type and show the server's errors by each field.
- [Release notes reader](release-notes/index.md): a page per release, loaded from JSON, with search.
- [Widget for any backend](widget/index.md): a custom element any site adds with one script tag.

You need Node 24 or newer. The [guide](../guide/index.md) explains each idea on its own.
