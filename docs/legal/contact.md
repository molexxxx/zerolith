# Contact

zerolith is developed in the open on GitHub, and that is where to reach the project.

- **Questions and ideas:** start a thread in [GitHub Discussions](https://github.com/molexxxx/zerolith/discussions).
- **Bugs:** [open an issue](https://github.com/molexxxx/zerolith/issues/new/choose) with the smallest code that shows the problem, and the diagnostic code when zerolith printed one.
- **Security issues:** report them privately through [GitHub private vulnerability reporting](https://github.com/molexxxx/zerolith/security/advisories/new), never in a public issue. The [security policy](https://github.com/molexxxx/zerolith/security/policy) says what happens next.
- **Changes:** pull requests are welcome, and [CONTRIBUTING.md](https://github.com/molexxxx/zerolith/blob/main/CONTRIBUTING.md) says how to make one.
- **Conduct:** the [code of conduct](https://github.com/molexxxx/zerolith/blob/main/CODE_OF_CONDUCT.md) applies wherever the project gathers, and says how to report a problem.
